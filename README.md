# Git実験用プロジェクト

このプロジェクトは、Gitのブランチ操作やバグ修正の流れを学習するための実験用プロジェクトです。

## プロジェクト構成

- `calculator.py` - シンプルな計算機アプリケーション

## ブランチ構成

- `main` - 本番用ブランチ（安定版）
- `develop` - 開発用ブランチ（バグを含む可能性あり）
- `fix/*` - バグ修正用ブランチ

## 使用方法

```bash
python calculator.py
```

## Git実験の流れ

1. mainブランチで安定したコードを確認
2. developブランチでバグを含むコードを発見
3. fixブランチを作成してバグを修正
4. 修正をdevelopブランチにマージ
5. 最終的にmainブランチにマージ
